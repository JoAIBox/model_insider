# 第三轮修复复核与交互教学深化方案

日期：2026-09-08。范围：审查当前工作区、浏览器代表性交互与数学计算；未修改应用代码。本文是后续实施方案，不是已经完成的修复记录。

## 1. 结论和已完成的改善

当前版本有实质进展，但“全部关键问题彻底修复、所有动画基于真实计算”仍不成立。主要缺口已从简单参数错误转向：计算定义与图形解释不一致、跨步骤状态缺失、教学示例被赋予未经验证的语义，以及训练／推理流程未贯通。

已确认改善：KDA 的 k/v/q 调用顺序正确；状态可递推；MLA 显存函数接收 d_c；移除了 MLA 内部的虚构 KDA 位置分支并增加输出门；AttnRes 可固定 pseudo-query 切换输入表示；视觉逆重构页替换为前向 projector 页；partial rollout 改为 4×4 轨迹；MOPD 使用三领域九配置；Newton–Schulz 支持高／宽矩形；输出页词表校准；MoE 双击导航正常。

## 3. 总体展示结构：围绕问题与因果组织

### 3.1 默认学习路径

基础运算 → 一次文本／图文前向 → K3 时间／深度／宽度创新 → 一次训练更新 → 推理缓存／投机／工具循环 → 实验与部署。

论文章节作为第二种索引保留。主导航不必删除现有模块，但首页先推荐这条路径，避免初学者直接面对17个同等权重入口。

每个模块用同一结构：

1. **问题**：传统方法的具体限制，用一个反例或成本项说明。
2. **改动**：只突出 K3 改变的操作及其位置。
3. **预测**：请用户先猜修改输入后哪个量会变化。
4. **执行**：每次只推进一个有意义的计算步骤。
5. **解释**：图、公式、数值三者指向同一 snapshot。
6. **边界**：哪些是论文结论，哪些只是本例现象。

### 3.2 统一页面骨架

```text
问题与目标     来源标签／真实规格与玩具尺寸
当前输入      t：token / l：层 / s：训练步
主计算图      本步输入 → 操作 → 输出／状态差
单步播放器    上一步／下一步／重置／播放／速度
结果解释      本次改变了什么，为什么
按需展开      数值表、公式推导、伪代码、来源、边界
```

默认首屏不同时展开整页公式和宽表。计算表应是主图的检查器，而不是独立附加的第二个模拟器。页面上的“播放”必须推进计算，不为静态图持续调用 requestAnimationFrame。

### 3.3 四种证据标签

统一使用“论文事实”“发布配置／参考实现”“可计算玩具示例”“结构示意”；实测数据再注明环境与来源。例子的确定性只证明可复现，不证明遵循 K3 算法，更不证明其语义或性能结论。

人工向量可命名“输入 A/B/C”，或“为解释句法／实体情境构造的示意输入”，不能标“真实语义预设”。不用固定比例曲线推断训练收益。不把完整模型、单层、单算子、单缓存项的指标混为一谈。

## 4. 分模块展示改善方案

### 4.1 架构总览与 MLA：先解决“发生在哪里”

**目标**：用户能说明一层有哪两个子层，KDA/MLA 互斥选择的位置，以及 AttnRes 如何为两个子层提供输入。

主图为重复层结构，展开任一层显示：AttnRes读取 → RMSNorm → KDA或MLA → partial sum累加 → AttnRes读取 → RMSNorm → Dense或MoE → partial sum累加。块边界封存摘要；最后聚合与输出归一化后进入词表投影。4层注意力周期与12层AttnRes分组使用两条独立标尺。

MLA 的专题图只展开该注意力模块：当前输入产生 query、KV latent 与 gate；历史 latent 集合经因果读取形成 o；g⊙o 后经过 W_o。不要在这里再引入原始 x 的普通残差捷径。历史 cache 有时间轴，而 gate 没有历史缓存支路。

提供“逻辑展开／latent 等价计算”开关，两种方式用相同小矩阵比较输出，门控留在正确的输入依赖位置。用户改变历史 token、当前 query、当前 gate 时，用不同高亮说明其作用范围。

**验收**：层类型和分组边界来自共享定义；MLA等价路径输出一致；未来位置权重为0；gate仅乘一次；返回总览仍保留当前层与token。

### 4.2 KDA：把“记忆更新”和“K3 的计算创新”拆成两段

**第一段：关联记忆计算。** 屏幕并排显示 S_old、S_bar、ΔS、S_new；颜色正负分开，点击任一单元显示等式。步骤依次为衰减、预测、误差、外积写入、query读取。显示数值输出向量，不能只画“Read”箭头。下一个token继承S_new，第一步的旧状态明确标为教学初态。

允许选择四类输入：δ=0；小δ；大δ；修改q但保持k/v/门不变。分别解释“没有delta修正”“修正小”“修正大”“只影响读取、不影响状态更新”。小δ并不意味着S_new≈S_old，因为衰减本身也可能很大；分别显示两个变化范数。

**第二段：K3门控与计算实现。** 使用可编辑z和A，直接算g=−5 sigmoid(exp(A)z)、α=exp(g)。同时显示Kimi Linear负Softplus对照；再展开16-token tile，展示累计log-decay范围及倒数缩放。最后连接到对角tile可用矩阵乘法的原因。

prefill／训练模式展示块内并行、块间递推；decode模式展示单步状态更新。以此说明“递推形式”并不等于训练只能串行。

**验收**：两种递推公式一致；q/k实际归一化；δ=0时ΔS=0但保留衰减；改变q不改S_new；门控曲线和矩阵使用同一α；回退／重置可复现。

### 4.3 AttnRes：把数据来源、权重与块状态连成一个演示

将“计算表”“高斯曲线”“93层图”合并为同一状态的三个视图。默认只显示embedding、已封存块、当前partial sum；只允许实际可见来源。不要在第1层仍显示虚构历史块。

固定w，切换A/B输入表示，逐步展示RMSNorm(keys)、dot scores、softmax、原values加权。条形图使用固定0–100%坐标，hover数值来自相同weights；显示总和的浮点容差，单项四舍五入可能不正好加到100.0%，不得调整计算值来迎合显示。

再推进子层：将子层输出累加到partial sum；越过块边界时封存。用第12→13层、最后第93层作边界例子。训练模式才能演示w参数更新，推理模式仅改变输入与激活。

**验收**：切token不改w；切层正确改变来源集合；keys归一化不改变values；图、表、公式一致。展示的来源权重不能由层距离或“句法/数学”标签直接生成。

### 4.4 MoE／QB／SiTU：解释三种不同问题，不混成一个均衡动画

**路由与容量**：保留已修正三分支图。以4专家Top-1/2玩具输入展示scores、bias、IDs、原始score归一化权重、专家输出、shared+routed合并。实际896/16配置放在固定规格栏，不能用玩具专家数替代。

**QB训练调度**：左侧固定batch s分数，按token标第k+1 cutoff；中间选择一个expert展开margin排序和q+1阈值；右侧显示candidate bias与去均值。按钮先只提交“下一批待生效偏置”，下一步才进入batch s+1。另设“同样本效果预览”，显式不代表真实当前batch重新路由。

选择多个固定种子批次展示负载变化，不承诺每批精确均衡。若展示旧固定步长法作比较，明确它不是QB。MoonEP另一个面板说明设备任务调度，不把专家路由均衡等同GPU利用率。

**SiTU稳定性**：分别编辑a=W_gx和b=W_ux，显示双支softcap与乘积。a=b=x只作为论文标量切片模式。给出界适用范围：激活乘积有界；后续W_out、残差和全训练loss不因此获得全局保证。

**验收**：bias不直接进入选中专家的混合权重；训练更新下一批生效；inference冻结；负载图由dispatch计数；SiTU两个输入可独立变化。

### 4.5 原生视觉：从“规格卡片”变成空间位置可追踪的前向

保留新的前向projector页，但把默认入口改为空间交互：56×56图→4×4 patches→视觉token→2×2分组→2×2输出token网格。点击patch，在后续packing中高亮其位置；编码后的特征是混合表示，不再声称某维固定代表耳朵／背景。

提供两层详情：真实shape 588→1024、Q/K/V每路1536→12×128、合并4096→MLP4096→7168→RMSNorm；玩具数值采用小矩阵，仅验证投影与重排操作。两个尺寸不能在同一公式中混用。

图像的空间重排可逆仅针对输入特征的排列；视觉编码、MLP与视频时间池化不保证无损。视频模式增加帧轴，明确哪一个时间组进行池化。NoPE是语言MLA属性，不推广为视觉塔也没有位置信息。

增加训练视角：文本next-token loss沿projector向视觉塔反传，解释“从头参与共同目标”与“冻结预训练视觉塔后接入”的区别。去掉看似可编辑prompt却始终输出photo/of/cat的“预测”错觉，或醒目标为脚本输出。

**验收**：patch/token计数一致；W₂列向量约定维度正确；包含post RMSNorm；图像／视频区别明确；不能由原始embedding相似度直接解释真实attention概率。

### 4.6 训练：增加一次可见的参数更新

默认使用4维、少token教学前向。先显示input与右移labels，再显示loss mask；点选监督位置看到logits、softmax、−log p(label)。执行backward后高亮梯度路径，下一步执行optimizer并显示参数前后差值，最后对同一输入重算预测。

更新步选择足够小的学习率验证该玩具例子的变化，不把一次loss下降表述为训练普遍单调。视觉输入位置和文本监督位置分开。μ/动量、梯度、参数、激活必须用不同标签。

Muon专题使用同一组2–4个完整momentum矩阵：先拼成全矩阵执行NS，再逐头分别执行NS，显示两个结果及每头更新范数／奇异值。步数滑块、主图、收敛表必须共用计算。加入秩亏与零块，解释有限步与秩限制。整矩阵Muon不是简单全局范数缩放，逐头也不保证每步都精确1.0。

长上下文课程改为“训练窗口／数据任务／成本”三栏，参数更新与上下文长度改变分开；不能拿推理KV cache计算当完整训练显存。Scaling-law优先引用原图；概念曲线用统一L(C)和坐标函数，若设定2.5倍横移则明确这是演示假设。

**验收**：labels与mask可检查；反向梯度用有限差分抽查；optimizer确实改变参数；NS主图跟随迭代；不再用无依据loss曲线证明收益。

### 4.7 后训练：以“样本生命周期”展示partial rollout与MOPD

把16条轨迹泳道铺满主要内容区域，量化表折叠到另一标签。右侧只放已完成结果池、可优化组队列与策略版本。

每条轨迹有不可变identity：prompt/group ID、response ID、起始策略版本；运行worker另有slot ID。状态至少包含running、paused、completed、consumed。达到λ阈值暂停unfinished；下一轮只恢复paused。未完整prompt里的completed结果留在结果池，等第K条完成后仅提交一次。新prompt/response采用新ID，不覆盖原结果。

提供四种事件按钮：完成一条轨迹、到达阈值、优化完整组、恢复下一轮。再提供自动播放。显示暂停前后进度和环境快照引用，让用户看到“保留了什么”；不要只切换颜色。已完成计数按当前活动批次定义，历史归档另计，避免累计历史结果使下一轮立即触发阈值。

MOPD默认只点亮一个领域×努力teacher。显示学生采样token、同一前缀下teacher/student概率、log ratio、clip结果。stop-gradient画在完整reward输出边界，另标teacher参数冻结；student的policy-gradient路径仍开放。若使用简化REINFORCE式更新，明确不是完整生产RL算法。修复两个general领域教师都缩写为T_gene造成的可见名称重复。

QAT用SFT→RL时间线说明贯穿阶段，局部标注routed weights MXFP4、相应activations MXFP8，shared、attention、router和latent projections保持较高精度。

**验收**：暂停恢复不丢结果、不重采未消费completed、不重复优化；组齐才能提交；相同种子回放一致；reward detach覆盖student分母路径，学生仍能通过policy loss获得梯度。

### 4.8 推理与投机：从“接受三枚”变成可检查的状态管理

先完成普通prefill→decode→采样循环：并排显示KDA状态、ShortConv状态、MLA历史latent；模型参数始终冻结。随后才启用draft。

用3词玩具词表和固定随机数，显示draft q、target p、每步min(1,p/q)及接受判定。拒绝时显示归一化max(p−q,0)修正分布；greedy验证另设模式。目标不是只展示速度，而是解释为何不改变目标采样分布。

将四个draft位置对应到状态有效前缀：MLA保留accepted prefix；KDA不能简单删除矩阵末尾行。展示projected input缓存、从已知前缀state在芯片上重放accepted inputs、写回验证／bonus token状态。和从接受前缀完整重算结果对照。

第二层解释EAGLE-3特征融合来源（第1、第4和最后AttnRes block）、MTP转draft、target冻结与训练展开；不要混淆draft训练和线上验证。保留性能时间轴但不填无依据毫秒数。

## 5. 展示与工程共同约束

1. **移动端重排**：390px使用纵向步骤，不等比压缩整张桌面SVG。关键文字实际显示至少12–14px，正文16px作为设计目标；复杂画布可缩放但提供可访问的文本步骤。不要用overflow:hidden掩盖内容超宽。
2. **统一播放状态**：每个模块一个step状态；数值、图形、说明共用snapshot。暂停终止timer/rAF/SMIL；切页和离屏暂停；reduced-motion显示静态步骤。
3. **公式渲染**：替换当前split式解析。使用可靠渲染或结构化数学组件；与伪代码分开；检查上下标、转置、矩阵维度和分式的渲染后文本。
4. **事实单点源**：各页面读共享spec，不重复硬编码。固定报告版本、配置commit和实现commit；每条公开规格记录来源；未披露量和部署可变项分别处理。
5. **教学计算单点源**：函数返回输入／中间量／结果快照；推荐参数对象避免k/v/q位置错传。主图不另写“看起来像结果”的函数。数学输入有明确shape约束和可验证失败，不静默生成NaN。
6. **缓存范围**：KDA state、ShortConv、MLA latent分项，区分dtype、batch、TP分片和前缀快照；把“理论状态项”与完整部署占用分开。OOM阈值由明确硬件预算确定。
7. **实验页面**：能力雷达、成本比较和耗时分解必须有同口径数据。缺失值仍缺失。2.5倍总体scaling效率不是任意区间严格拟合，也不是单个组件收益；1.25倍效率对应20%而非25%计算节省。
